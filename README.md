# Gas-to-Electric RC Aircraft Conversion

## Project Overview

This project involved converting a gas-powered radio-controlled (RC) aircraft to electric propulsion. The original power system was replaced with an electric motor and propeller setup, with a rechargeable battery and electronic speed controller (ESC) powering the aircraft.
The converted aircraft was successfully flown, demonstrating that the electric propulsion conversion worked in real-world operation.

## Project Objectives

- Replace the original gas-powered propulsion system with an electric propulsion system.
- Integrate the electric motor and associated electronics into the existing airframe.
- Package the battery and electronic components within the fuselage.
- Preserve the aircraft's ability to operate under radio control.
- Validate the completed conversion through a successful flight test.
- Reconstruct the aircraft and propulsion installation in SOLIDWORKS for engineering documentation.

## Main Components

| Component | Function |
|---|---|
| Airframe | Existing fuselage, wings, tail, and landing gear that support the aircraft. |
| Spektrum Avian brushless motor | Provides the thrust needed to propel the aircraft. |
| Propeller and adapter | Transfers motor rotation into thrust. |
| Electronic speed controller (ESC) | Regulates electrical power delivered to the brushless motor. |
| Rechargeable flight battery | Supplies electrical power to the propulsion system and onboard electronics. |
| Spektrum AR410 receiver | Receives commands from the radio transmitter and relays control signals. |
| Motor mount and mounting hardware | Secure the motor to the airframe. |
| Wiring and electrical connectors | Connect the battery, ESC, motor, receiver|


## Conversion Process

### 1. Electric Propulsion Integration

Replaced the original gas-powered propulsion setup with an electric motor and propeller system. Integrated the motor with the existing aircraft structure.

### 2. Electrical System Integration

Used a rechargeable flight battery, ESC, and radio receiver as part of the electric propulsion and control system. The ESC regulates motor operation in response to throttle commands received through the radio-control system.

### 3. Component Packaging

Accommodated the battery and electronic components within the fuselage while retaining the aircraft's existing airframe configuration.

### 4. Flight Testing

Successfully flew the converted aircraft to verify that the integrated electric propulsion system could operate as part of the complete RC aircraft.

## Results

- Successfully converted a gas-powered RC aircraft to electric propulsion.
- Achieved successful flight with the converted aircraft.
- Gained hands-on experience with mechanical assembly, electric propulsion integration, and radio-controlled aircraft systems.
